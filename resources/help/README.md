# Встроенная справка по синтаксису 1С

`shcntx_help.db` — SQLite-база справки платформы 1С. В репозитории находятся 24 787 строк таблицы `nodes` (`id`, `parent_id`, `name`, `path`, `content`): исходные 2673 узла и 22 114 дополнительных HTML-статей. Таблица `article_markdown` содержит отображаемый Markdown для страниц с разрешёнными внутренними ссылками; `node_id` ссылается на строку `nodes`.

Импортёр сохраняет видимые подписи и порядок ссылок из HTML. Ссылки превращаются в `bsl-help:syntax:<id>` только если их путь разрешился в существующую статью этой базы. UI показывает их как внутренние ссылки на ID; адреса сайта, неподдерживаемые схемы и traversal-пути кликабельными не становятся. Исходное поле `nodes.content` остаётся поисковым текстом.

Расширение читает базу только в памяти через sql.js; запросы пользователя не исполняются как SQL, а база и файлы приложения не изменяются.

## Обновление из архива платформы

Импортёр `scripts/import_bsl_syntax_help.py` использует только стандартную библиотеку Python. Перед изменением базы он проверяет SHA-256 исходного `shcntx_ru.hbk` и исходной SQLite-базы. Скрипт читает встроенный ZIP по закреплённым смещению и длине, не распаковывая файлы на диск. Старые строки сохраняются, новые страницы добавляются по пути; повторный запуск на уже обогащённой базе проверяет результат и ничего не меняет.

Запуск из корня репозитория:

```powershell
python scripts/import_bsl_syntax_help.py --hbk "C:\Program Files\1cv8\8.3.27.1859\bin\shcntx_ru.hbk"
npm run generate:bsl-completion-index
```

Файл `.hbk` не хранится в репозитории. Скрипт принимает его путь через обязательный аргумент `--hbk`; `--db` позволяет указать SQLite-файл, по умолчанию используется `resources/help/shcntx_help.db`.

`resources/standards/manifest.json` содержит заметки проекта по стандартам разработки. Каждая заметка даёт ссылку на соответствующий официальный материал ИТС для проверки версии и области применения.

`bsl-completion-index.json` — компактный статический индекс подсказок BSL, генерируемый из этой базы командой `npm run generate:bsl-completion-index`. Поле `sourceSha256` и core-тест гарантируют, что индекс соответствует версии SQLite; при разработке completion provider читает только JSON, без sql.js и WASM.

Проверки импортёра и собранной базы: `python -m unittest scripts.test_import_bsl_syntax_help -v`.

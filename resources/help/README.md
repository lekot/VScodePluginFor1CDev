# Встроенная справка по синтаксису 1С

`shcntx_help.db` — собранная владельцем проекта SQLite-база справки платформы 1С. В версии, включённой в расширение, находится 2673 узла в таблице `nodes` (`id`, `parent_id`, `name`, `path`, `content`).

Расширение читает базу только в памяти через sql.js; запросы пользователя не исполняются как SQL, а база и файлы приложения не изменяются.

Рядом с базой находятся оригинальные заметки проекта по стандартам разработки (`resources/standards/manifest.json`). Каждая заметка даёт ссылку на соответствующий официальный материал ИТС для проверки версии и области применения.

`bsl-completion-index.json` — компактный статический индекс подсказок BSL, генерируемый из этой базы командой `npm run generate:bsl-completion-index`. Поле `sourceSha256` и core-тест гарантируют, что индекс соответствует версии SQLite; при разработке completion provider читает только JSON, без sql.js и WASM.

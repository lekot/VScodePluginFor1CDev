# Однотипные запросы в цикле

Если обработке нужны однотипные данные для многих объектов, сначала попробуйте получить их одним запросом. Используйте отбор по списку, объединение или пакет запросов, а затем сопоставьте результаты с исходными объектами. Так база не выполняет одинаковую работу при каждом проходе цикла.

Циклические запросы могут быть оправданы, когда они нужны для порционной обработки большого объёма, уменьшают сложность запроса или оказываются быстрее из-за особенностей виртуальной таблицы. Это решение подтверждайте измерением, а не предположением.

Для функций БСП выбирайте массовый вариант программного интерфейса, если он предусмотрен. Например, пакетное получение значений обычно лучше повторного вызова метода для каждого объекта.

**Проверка:** измерьте время и число запросов на реалистичном объёме. После объединения проверьте план запроса и потребление памяти.

Итог зависит от структуры данных и версии платформы; рекомендация не запрещает обоснованную обработку порциями.

Источник: [Многократное выполнение однотипных запросов, стандарт #std436](https://its.1c.ru/db/content/v8std/src/300/100/i8100436.htm).

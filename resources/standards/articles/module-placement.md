# Общие модули и границы сервера

Флаги общего модуля задают, где его код доступен и может исполняться. Флаг «Вызов сервера» открывает серверные процедуры клиентскому коду, поэтому такой модуль должен содержать только операции, которые действительно составляют клиентский интерфейс.

Для каждой экспортной серверной процедуры проверяйте два пункта: какие данные она принимает и какие данные возвращает. Не отдавайте клиенту исходные или промежуточные данные, к которым текущий пользователь не должен иметь доступ. В серверном модуле оставляйте внутренние операции без флага «Вызов сервера».

Серверные и клиентские модули разделяйте по роли. Если алгоритм нужен обеим сторонам, вынесите общую часть в подходящее место, а не открывайте весь модуль на сервер.

**Проверка перед публикацией API:** составьте список публичных процедур общего модуля и подтвердите, что каждой из них нужен клиентский вызов.

Правила зависят от режимов приложения и возможностей платформы. Проверяйте применимость стандарта к целевой конфигурации.

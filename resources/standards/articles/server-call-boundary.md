# Граница вызова сервера

Серверный общий модуль с признаком «Вызов сервера» доступен для клиентских вызовов. Оставляйте этот флаг только у модулей с намеренно открытыми процедурами и функциями. Серверная логика, которую клиенту вызывать не нужно, должна оставаться вне такой границы.

Считайте каждую экспортную процедуру серверного модуля частью прикладного API. Проверьте, что она:

1. принимает минимальный объём параметров;
2. возвращает только данные, доступные текущему пользователю;
3. не выполняет дорогостоящую работу в обработчике, который должен быстро ответить пользователю.

Подсчитывайте не только явно написанные вызовы, но и вызовы, возникающие из-за обращений к клиентским общим модулям и контексту формы. Объединяйте независимые серверные операции, когда это уменьшает задержки без чрезмерной передачи данных.

**Проверка:** используйте профилировщик и тестовый сценарий в целевом клиенте; одно число вызовов без измерения переданного объёма не даёт полной картины.

Стандарты относятся к поддерживаемым режимам приложения, но детали оптимизации меняются с версиями платформы.
